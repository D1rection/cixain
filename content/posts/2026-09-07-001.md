在很早的时候就想搭一个博客来着了。在大一的时候自己用 React 手搓了一个粗糙的博客模板出来，但是最终没有使用（那时候 vibe coding 还没有成熟，自己用 JS 和 CSS 捣鼓一下午的动效还是比较有成就感的。目前这个站点是纯 vibe coding 得到的）。

为什么要搭一个博客呢？就我自己而言，原因可能有下面几点：

- 对技术博客一直有一些憧憬
- 比较抗拒在「QQ \ 朋友圈」发表内容
- 想要记录一下自己

> 第一点应该不用解释，我感觉有一个技术博客应该是一件比较酷的事 :p
> 第二点则是我自己的一个缺点吧。这里暂且不谈，总之是选择了逃避。

第三点是一个尤其重要的原因。每当隔了一定的时间跨度，我就总会在某个节点感觉到自己现在的想法跟过去是有很多出入的。因此，需要一份记录，告诉我自己现在跟过去到底发生了哪些变化，输出的观点究竟是长期的还是短期的。于是乎，这个博客就诞生了。
