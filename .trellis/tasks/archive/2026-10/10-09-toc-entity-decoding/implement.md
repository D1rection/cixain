## 回归矩阵

| 场景 | 预期 |
| --- | --- |
| 实际 CS229 标题 | `文字显示 &，ID 与修改前一致` |
| 十六进制、十进制、命名实体 | 正确显示符号、引号、NBSP 与其他命名字符 |
| `&amp;#x26;` | `只解码一次，得到字面量 &#x26;` |
| 编码后的 img 标签文字 | 文字保留，React 不生成 img 元素 |
| emoji、非法码点、未知实体 | 正确显示或替代，不抛错，未知实体保持原文 |
| 强调、链接、行内代码标题 | 去真实标签、保留文字 |
| 预置 ID、块 ID、无 ID、重复标题 | ID、编号和跳转与修改前一致 |
| 空输入、fold、已有公式标题 | 不回归；不改公式文字既有语义 |
| SSR Probe 调用真实 hook | 不依赖 document，toc.text 和 React 转义结果正确 |
| 历史比较 fixture | toc.text 正确、编号不变、版本含后缀并进入 generation，相同构建 generation 稳定 |

普通目录测试使用 React 服务端渲染 Probe 调用真实 hook，无需为测试重构 hook。历史比较扩展现有临时 Git 仓库 fixture，不改真实文章。expected 使用明确文字，不用被测函数计算预期。
