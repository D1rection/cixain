# 文章参考链接板块

## Goal

为文章引入「参考来源」板块：作者在文末手写 `## 参考` + 有序列表，构建时自动识别并渲染为两行式引用条目（标题链接行 + 淡色 URL 行），参考链接开新窗口。解决现有文章「引用了外部来源却无出处」的问题。

声明方式为**文末手写列表**，无特殊语法，Obsidian 中即可正常预览。

## Requirements

- 作者在文章末尾写 `## 参考`（或 `## 参考资料` / `## References`）+ 有序列表，每个条目两行：
  - 第一行：来源标题（可为链接，也可纯文本）
  - 第二行：URL（裸 URL，缩进续行）
- 构建时自动识别该板块并套用专属样式，**作者无需任何标记语法**
- 参考列表条目渲染为两行式：标题行保持正文链接样式，URL 行淡色小字
- 参考列表内的链接 `target="_blank"` + `rel="noopener noreferrer"` 开新窗口
- 识别规则不得误伤：
  - 正文其他 `h2`/`h3` 标题不受影响
  - 正文其他有序/无序列表不受影响
  - 标题文本相似但不精确匹配的（如「参考实现」「参考文档」）不命中
  - 标题后跟的不是列表（如段落）不命中
- 单行条目（只有标题无 URL）也能正常渲染
- 写作模板（Templates/new-post.md）加入参考板块示例
- 现有文章**暂不回填**，从新文章开始生效

## Acceptance Criteria

- [ ] 写 `## 参考` + 两行式有序列表 → 渲染为参考样式（标题行 + 淡色 URL 行），链接开新窗口
- [ ] 单行条目（仅标题）正常渲染，不报错、不变形
- [ ] 条目标题为纯文本（无链接）时正常渲染，URL 仍可点击
- [ ] 正文其他列表（ul/ol）样式不变
- [ ] 标题为「参考实现」等内容时不命中
- [ ] `## 参考` 后跟段落（非列表）时不套样式
- [ ] 正文普通链接仍同窗口跳转（行为不变）
- [ ] Templates/new-post.md 含参考板块示例
- [ ] spec 更新（content-pipeline.md）
