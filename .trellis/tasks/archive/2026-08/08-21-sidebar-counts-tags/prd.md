# 侧边栏分类计数与标签加权

## Goal

改进首页侧边栏：分类显示文章数量，标签按热度（文章数）加权展示，提升信息密度与可读性。

## Requirements

- **分类带计数**：侧边栏每个分类链接旁显示该分类的文章数。
  - 无文章的分类（如当前「Life」，0 篇）保留显示，计数为 `(0)`。
  - 计数基于构建期数据（`posts`，与全站一致：生产构建已剔除 draft，dev 模式含 draft）。
- **标签按热度加权**：标签块按文章数降序排列，每个标签显示数量徽标，热门标签（文章数多）字号微调放大，冷门标签保持基础字号。
- 仅修改 `src/components/Sidebar.jsx` / `Sidebar.module.css`，不改动其他组件、数据结构和构建管线。

## Acceptance Criteria

- [ ] 「分类」块每个分类显示文章计数，`Life` 显示 `(0)`。
- [ ] 「标签」块按文章数降序排列；每个标签显示数量；文章数多的标签字号明显大于少的（至少两级差异化；同级内保持稳定顺序如有需要可用名称排序兜底）。
- [ ] 系列块行为不变；计数与「系列」块现有篇数样式风格保持一致（`seriesCount` 同体系）。
- [ ] 计数与首页对应分类/标签筛选结果一致（如 `/category/Life` 为空时计数为 0）。
- [ ] `npm run build:posts` 或现有构建通过，样式无回归（现有 hover/active 态保留）。

## Notes

- 轻量 UI 任务，PRD-only，无需 design.md / implement.md。
- 参考现有实现：`seriesCount` 徽标样式、`tag` chip 样式。
