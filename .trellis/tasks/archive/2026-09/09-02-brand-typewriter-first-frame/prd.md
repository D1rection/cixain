# 修复品牌打字机首帧偶发异常

## Goal

让导航栏品牌在静态 HTML 首帧就稳定可见，避免页面加载阶段只出现光标或短暂空白，同时保留后续打字机循环动画。

## Requirements

- 服务端预渲染与客户端水合的初始品牌文案必须一致，首帧直接显示完整的 `Cicada's blog`。
- 首帧稳定展示一段时间后，再进入删除与输入循环，继续在 `Cicada's blog` 和 `cixain` 之间切换。
- 组件卸载时必须清理当前动画定时器，避免残留回调更新已卸载组件。
- 不改变导航栏布局、链接、主题切换、背景切换及移动端交互。

## Acceptance Criteria

- [x] 构建产出的静态 HTML 中，品牌元素首帧包含完整的 `Cicada's blog`，而不是空字符串。
- [x] 品牌的服务端与客户端初始文案一致，加载后先保持完整文案，再正常执行删除和下一段输入。
- [x] 快速卸载或路由生命周期变化不会留下未清理的打字机定时器。
- [x] 生产构建通过，桌面端和移动端导航视觉与交互无回归。

## Notes

- 本任务为局部、低风险的交互修复，采用 PRD-only 轻量流程。
- 修复前基线与修复后本地预览均存在 React `#418` 水合告警；其与品牌初始文案无关，不属于本任务新增回归，后续应单独排查。
