# 设计：主题共用正文排版参数

## 决策

采用现有 light 排版作为统一基准。1.75 与 1.8 都属于合理中文阅读行高；选择前者是为延续现有浅色布局和 28px 间距体系，并非宣称它具有普遍阅读优势。已有标题和公式具有不同高度，28px 是间距参考，并不代表全文严格逐行对齐。

| 参数 | light 当前 | dark 当前 | 统一值 |
|---|---|---|---|
| --content-line-height | 1.75 | 1.8 | 1.75 |
| --content-letter-spacing | 0 | 0.01em | 0 |
| --quote-line-height | 1.9 | 1.95 | 1.9 |
| --quote-math-line-height | 2.1 | 2.15 | 2.1 |

正文继续继承浏览器字号（默认通常为 16px），不新增固定字号。引用的局部行高保留，避免降低公式推导区域的容纳空间。

## 实现边界与数据流

`useTheme → html[data-theme] → 主题颜色变量 → CSS 绘制`。正文几何变量移至独立的共享 `:root` 声明，两种主题共同继承；主题状态变化不再覆盖这四个值。

计划涉及三个文件：

- `src/styles/global.css`：将四个排版变量移入独立共享 `:root` 块；从 dark 移除对应覆盖；引用背景颜色仍由主题控制。更新暗底补偿注释。
- `src/components/PostContent.module.css`：保留变量消费方式；更新正文、引用、代码与公式的注释，将“阻断暗色补偿”改为“代码/公式保持独立字距”等实际约定。
- `.trellis/spec/frontend/typography.md`：以主题无关的排版约定替换暗底补偿条款，保留代码/公式字距隔离、标题、引用和折叠题干规则。

不修改 hook、组件结构或构建脚本。保留现有变量名，使折叠题干、关于页及历史比较内容自动获得相同基准。字体族、字重、宽度、边距不随本任务调整。

## 方案取舍

- 统一为 1.75 / 0：采用。浅色阅读布局不变，暗色消除已确认的行高和字距差异。
- 统一为 1.8 / 0：可行，但会重新排版两种主题中的浅色长文，本次缺乏支持全局调整的实际阅读证据。
- 改为 17px 或缩窄正文：属于后续阅读体验实验，本次不采用。
- 保存并恢复 scrollTop：不能防止字符重排，且会介入现有滚动目标与目录定位机制，本次不采用。

## 兼容性与风险

沿用现有 CSS 自定义属性，SSG 初始主题、客户端切换及 auto 模式均能使用同一组值。保留 pre/code/KaTeX 的字距隔离，以及公式引用局部行高。

暗色长文会比旧版本稍紧凑，这是预期变化。字体和懒加载图片仍可能独立改变布局，验收需等待资源稳定并记录图片加载事件，不能把它们误判为主题回归。

Shiki 暗色规则另外覆盖 token 的字重/斜体；目前尚未确认它导致代码几何差异。本轮方案不修改语法高亮。如实测发现代码宽高受影响，记录证据并补充设计后再扩展实现，不能先宣称全站所有文字几何均稳定。

移动端通过独立滚动容器阅读。验收需区分容器内部正文坐标与导航菜单开合造成的视口变化；比较两次相同的导航状态。

## 验证设计

桌面 1440px、移动端 375px/768px、桌面断点侧 769px。固定视口、缩放、字体、折叠状态和滚动位置；等待字体完成加载及可见图片稳定。

代表内容：`2026-09-27-001`（朴素贝叶斯：长段落、callout、公式）、`2026-09-23-001`（GDA：公式推导）、`2026-08-26-002`（LC231：折叠题干与代码）、`/about`。另选现有带表格及可用历史比较数据的文章。

比较 light → dark → light 的 computed style、正文换行、段落/标题/容器矩形、scrollHeight 和实际滚动目标的 scrollTop/scrollY。页面顶部与长文中部均检查；源码属性切换用于隔离几何问题，真实按钮循环及刷新用于验证交互。坐标允许 1 CSS px 采样误差，但不允许新增换行。

## 回滚

仅撤销本任务对上述三个文件的变更，并同步恢复对应规范。不得使用整仓恢复或覆盖用户既有未提交内容。回滚会恢复原主题差异，应在记录中说明。
