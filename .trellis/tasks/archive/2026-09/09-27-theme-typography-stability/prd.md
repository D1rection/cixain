# 统一明暗主题正文排版，消除切换位移

## 目标与授权

用户在阅读博客时发现 light/dark 切换导致文字移位。目标是在保留现有中文、代码与公式阅读体验的同时，让主题切换前后的正文排版稳定。

2026-09-27：用户已授权创建任务、完成设计并开始实施。

## 已确认事实

- 正文主题参数存在差异：行高 1.75 / 1.8，字距 0 / 0.01em。
- 普通引用行高为 1.9 / 1.95，含公式引用段落为 2.1 / 2.15。
- 这些差异会改变行盒高度并累积移动长文内容；变更前的浏览器实测确认正文总高相差 164.74px（light 11308.40px，dark 11473.14px）。详细值见 `research/validation.md`。
- 文章、关于页共用 PostContent 样式，折叠题干也使用正文行高变量。
- 现有排版规范明确要求暗色补偿，实施时必须同步更新该约定。

## 需求

1. light/dark 使用同一套正文、引用、公式引用排版参数；切换不得改变正文换行、段落高度及阅读位置。
2. 共用基准采用既有 light 数值：默认约 16px 正文、1.75 行高、0 额外字距；普通引用 1.9，含公式引用段落 2.1。
3. 保持现有内容宽度、字体、字号、段落间距、标题层级和代码/公式局部排版。
4. 保持两种主题各自的配色、背景、引用外观，以及 auto/light/dark 操作语义。
5. 覆盖文章正文、列表、表格、callout、展开的折叠题干、历史比较内容与关于页；支持桌面和移动端。
6. 新的排版规范应防止后续重新引入仅由主题切换触发的几何变化。

## 验收标准

- [x] 四个排版变量在 light/dark 下值完全一致；桌面文章、移动文章、折叠题干与 about 页的计算样式相同。
- [x] 代表性段落、引用、表格与文章容器在两个主题间的测量尺寸一致；原始 CSS 的长文高度差为 164.74px，统一后实测的主题间几何尺寸相同。
- [x] 桌面和移动端长文中段切换后位置稳定：桌面比较页 `scrollY=12033.5px`、当前标题 `top=59.93px`，移动文章滚动容器 `scrollTop=9718px`、当前标题 `top=112.77px`，切换前后完全相同；未新增滚动补偿逻辑。
- [x] 数学引用及公式、代码块、表格和展开的折叠题干已在代表文章中核对，没有观察到新增重叠、裁切或溢出。
- [x] about 页使用共享参数且切换稳定；历史比较页载入 6 处真实修订并核对了主题切换，排版位置稳定。
- [x] auto/light/dark 循环可用，dark 偏好在刷新后保留；light 的排版基线与变更前一致。
- [x] 活动排版规范及源码注释与共享主题几何实际行为一致。
