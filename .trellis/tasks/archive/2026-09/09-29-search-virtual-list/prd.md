# 搜索结果动态高度虚拟列表

## Goal
搜索结果随内容增长仍可连续浏览，取消“显示更多结果”，限制实际渲染节点数量，并保持完整的键盘和读屏导航。

## Requirements
- 保留搜索弹层、标题、最多两行摘要和可选匹配标签，不显示文章/碎片类型。
- 输入框下显示“共 N 条结果”；空查询保留引导文案，加载、错误重试和空结果状态完整。
- 使用成熟库实现动态高度虚拟列表，可连续滚动至全部结果，取消每批 10 条的限制。
- 修改关键词回到顶部并选中第一条；方向键遍历全量结果并自动滚入视野，Enter 打开，Esc 关闭，保留中文输入法保护。
- 保留真实链接、中键/修饰键、焦点锁定与恢复、背景滚动锁定。
- 动态测量适应标题换行、摘要/标签差异、窄屏、字体加载和缩放。

## Acceptance Criteria
- [x] 0/1/10/1000 条结果总数正确，无更多按钮；1000 条均可到达，DOM 数量不随总数线性增长。
- [x] 桌面和 320px/390px 窄屏下，混合高度条目无重叠、异常空洞或标题截断。
- [x] 深处改查询、清空、关闭重开后滚动与选择正确重置。
- [x] 方向键跨视口及第 10 条边界正常；手动滚动不会被旧选择拉回。
- [x] activedescendant 始终指向已挂载节点，条目声明全量位置与总数，Tab 不遍历虚拟节点。
- [x] IME 确认不误打开；Enter、点击、中键/修饰键、Tab 环、Esc 和焦点恢复正确。
- [x] 宽度、字体、缩放改变后测量正确，尾项可达。
- [x] SSG 构建通过；浏览器验证记录设备、数据规模和 DOM 数量，未实测的辅助技术行为明确标记。

## Out of Scope
索引格式、召回/排序、高亮算法、Worker、服务端搜索、索引分片、独立搜索页面、日期模板。
