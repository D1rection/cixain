# 文章历史版本阅读与内联差异展示

## Goal

参考 Patrik 的 Show your AI writing work，让读者在文章顶部选择旧版，并在正文中阅读单栏内联差异。默认展示最新版。
本轮只交付 Trellis 任务与方案，保持 planning。

## Confirmed facts and decisions

- 用户授权创建任务和设计，尚未要求实施产品代码。
- 用户已确认自动收录已提交、非草稿且正文变化的版本，合并连续重复内容。
- 项目为 Markdown + Git + React/wouter + Vite SSG，无运行时后端。
- 当前只有最新正文和 updated 日期，但文章已有 Git 历史。
- 原文含代码、公式、图片、表格、Obsidian 链接/块引用、callout 和交互组件。

## Requirements

- 选择器位于标题/标签后、目录前；有不同旧正文时才显示。
- 小幅文字修改使用词句级增删，未变文字正常；整段增删明确标记。
- 同日版本通过日期时分区分，提交时间不称上线时间。
- 比较状态可分享、刷新、前进后退，随时返回最新。
- 中文、英文、emoji 正常；复杂结构至少提供完整块级替换。
- 历史请求失败/无效版本时保留最新正文并提供退出或重试。
- 默认正文首屏、目录、锚点、主题、图片、移动滚动和当前交互不退化。
- 草稿、未提交正文、删除文章不进入公开历史产物。
- 首次阅读不加载全部历史正文；历史不进入搜索、Feed、sitemap。

## Scope

首版：旧版→当前最新版，段落/简单列表项短语 diff，复杂结构块级替换。
后续候选：代码行 diff、表格单元格 diff、变更导航、折叠未改正文、人工修订说明。
不包含：任意两版比较、独立旧版页面、AI 过程披露、后端数据库、上次阅读快照、历史图片二进制归档。

## Acceptance criteria

- [ ] 默认 SSR/水合内容一致，单版本无选择器。
- [ ] 选旧版正文出现单栏增删，返回最新无残留；改单句不将整段判为重写。
- [ ] frontmatter-only 提交不产生版本；A→B→A 回退保留，不全局去重。
- [ ] 同日多个版本可区分，时区明确。
- [ ] 中文/英文/emoji/链接目标变化/段落增删有验证样例。
- [ ] 代码/公式/图片/表格/callout/react: 内容不产生破损 HTML 或执行历史交互。
- [ ] 深链刷新、前进后退、快速连选、跨文章导航不串用响应。
- [ ] 404、未知版本、错误 generation 时保留最新版并可恢复。
- [ ] 375px、深浅主题、键盘可用，无页面整体横向溢出。
- [ ] 目录仅指向当前标题，旧内容无重复 id；图片与阅读进度正常。
- [ ] 产物不含草稿、未提交正文或删除文章。
- [ ] 普通阅读不请求比较正文，列表页不注入全站历史正文。
- [ ] 相同输入产物一致；严格生产构建缺完整历史时明确失败。

## Open questions

无阻塞产品问题。具体 diff 依赖与局部配对阈值留实施时基于官方文档和 fixture 确定。
