# 文章属性控制首页可见性

## 目标

允许作者通过文章属性决定是否进入首页，不再由文章分类决定首页可见性。RSS 继续独立排除题解分类。

## 已确认事实

- 当前首页按分类排除 `Soln`，RSS 也复用同一配置；本任务将两者拆开。
- 首页先过滤再分页；分类、标签、系列页使用独立筛选逻辑。
- 目前 Markdown 源文件中共有 6 篇 Soln 文章，均无首页可见性属性。
- 首页静态数据保留全量文章元数据，渲染列表时过滤；分类计数依赖完整数据。
- 工作区已有用户未提交的文章、模板、Obsidian 配置和生成文件变更。

## 建议需求

- 新增可选布尔属性 `showOnHome`：缺省或 true 显示，false 隐藏，适用于所有分类。
- 隐藏文章不占首页分页数量；首页的 tag/category 查询参数不能绕过该属性。
- 分类、标签、系列、归档、搜索、相关推荐、文章详情和搜索引擎收录不受首页属性影响。
- 草稿和未来日期仍遵循已有发布规则；`showOnHome: true` 不能强制发布。
- 现有 6 篇题解显式迁移为 false，保留当前首页展示结果；题解模板默认 false，普通文章模板默认 true。
- 不支持通过分类隐式补默认值；新题解省略属性也应默认显示。
- 错误类型给出文件名及字段提示并使构建失败，避免字符串 `"false"` 被误认为有效设置。
- RSS 保持当前排除 Soln 的行为，并与首页属性解耦。

## 验收标准

- [x] Tech/Life/Soln 均满足缺省、true、false 的统一首页规则。
- [x] 首页第一页和后续分页都无隐藏文章，分页总数只计算可见文章。
- [x] `/?category=Soln` 可展示显式允许或缺省允许的题解；隐藏题解仍不可见。
- [x] `/category/Soln/`、标签、搜索、归档及直接文章链接仍可访问已发布的隐藏文章。
- [x] 6 篇历史题解迁移后首页结果与迁移前一致。
- [x] dev、静态首屏和客户端水合遵循同一属性；首页内联元数据仍保留隐藏文章。
- [x] 缺省字段生成 true；非法类型如字符串、数字、null 不能静默通过。
- [x] RSS 继续排除 Soln，不受 `showOnHome` 改变；sitemap 保留已发布隐藏文章。
- [x] 模板与项目规范说明新字段及默认值。

## 范围外

置顶/排序、首页访客切换按钮、私密文章/权限控制、逐文章 RSS 属性、已有 SPA 数据范围问题及无关分页缺陷。
