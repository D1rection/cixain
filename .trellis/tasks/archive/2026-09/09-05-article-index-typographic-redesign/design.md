# 文章索引排版式重设计 — 技术设计

## 1. 设计判断

上一版虽然去掉了直角方框，但同时使用圆角卡片、时间线和胶囊 chip，三类内容缺少共同语法。初次排版方案又过度放大 Steph Ango 的大标题与满宽密度，和归档页不协调。本次以归档页为母版：沿用它的 680px 内容宽度、双层页面留白、小号像素标题、细分隔线与紧凑列表，只保留编号、文字和计数作为索引层级。

## 2. 页面骨架

```text
文章索引
17 篇文章

01 分类
技术  13       随笔  0       题解  4

02 系列
01  算法                         2 篇
02  CS229 机器学习              8 篇
03  图形学                       2 篇

03 / 标签
#CS229 8   #机器学习 8   #位运算 3
#CSP认证 2  #LeetCode 2  ...
```

页头不添加说明句，不使用大号展示标题。标题与文章数直接复用归档页的视觉层级。

## 3. 视觉语法

- 区块标题采用 `01 / 分类` 一类的编号语法，像素字体仅用于编号或路径。
- 分类使用文字与计数，不使用独立容器背景；移动端可三列或自然换行。
- 系列采用与归档文章行一致的 CSS grid，对齐编号、名称和篇数；不使用会让页面显得像另一套系统的强装饰。
- 标签采用普通链接组成的 flex-wrap 文字云；计数使用小号基线/上标，不通过标签字号大幅缩放。
- hover/focus 只改变 accent、短下划线或局部背景，不让整块浮动。
- 使用现有 CSS 变量适配浅/深主题，不新增主题状态或图片资产。

## 4. 代码边界

- 主要修改 `Browse.jsx` 与 `Browse.module.css`。
- `NavBar`、`buildTaxonomy`、路由和 SEO 逻辑原则上不修改；只有静态文案发现回归时才做最小修正。
- 保留语义化 `main/header/section/h2/a` 和现有链接生成方式。

## 5. 回滚

视觉改动集中在文章索引组件；如需回滚，可恢复该组件 JSX/CSS，不影响导航入口、taxonomy 聚合或 `/browse/` 静态路由。
