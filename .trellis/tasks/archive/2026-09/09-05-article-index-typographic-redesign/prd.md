# 文章索引排版式重设计

## Goal

重新设计移动端文章索引页。以博客现有归档页作为字号、内容宽度、四周留白和交互反馈的首要视觉基准，只从 Steph Ango 个人网站借鉴无卡片化和排版组织方式，使索引页自然融入博客而非形成独立风格。

## Requirements

- 页面继续使用「文章索引」名称及 `/browse/` URL，不改变路由、canonical、sitemap 或分类/系列/标签目标地址。
- 采用排版优先的单栏索引，不再使用圆角分类卡片、系列时间线、胶囊标签或大面积浅色组件底板。
- 页头与归档页使用同一套紧凑结构，只展示小号像素标题「文章索引」与文章总数，不使用大号展示标题、英文 `entries` 或路径标识。
- 页头不展示「按主题和阅读路径，翻找这里的文章」或其他解释性、引导性、营销式文案。
- 分类、系列、标签使用统一的“文字目录”视觉语法，但各自保留适合内容结构的排列方式：
  - 分类：横向或自适应文字入口，名称为主、数量为弱化的上标或旁注；
  - 系列：纵向紧凑列表，使用稳定编号、对齐或点状引导线连接系列名与篇数；
  - 标签：无外框的文字主题云，通过颜色浓度、字重和计数表达热度，不使用大小悬殊的字号变化。
- 视觉优先对齐现有归档页：内容宽度 680px、页面四周留白、小号像素标题、细分隔线、4px 小圆角和轻量 hover 底色。Steph Ango 只作为无卡片文字组织的次要参考，不照搬其大字号、满宽密度、黑白配色或页面结构。
- 融合本博客既有视觉语言：
  - 浅色主题使用暖纸色、锈红 accent 和轻微纸张纹理；
  - 深色主题使用 CRT 近黑背景、终端绿 accent 和现有暗色文字层级；
  - 像素字体只用于路径标识、区块编号、计数等小型元信息，正文名称继续使用可读性更高的系统字体；
  - 装饰控制在短线、像素点、光标或角标等少量细节，不加入插画、远程图片或完整终端窗口外壳。
- 页面内所有交互项继续保持至少 44px 的移动端触控高度或等效点击范围，并提供清晰的 hover、focus-visible、active 状态。
- 在 320px、375px、768px 下保持无横向滚动；长系列名允许省略或安全换行，不能挤压篇数到不可读。
- 移动端菜单继续保持当前 6 个纯图标入口和顺序，不恢复可见文字；桌面导航与侧栏保持不变。
- 继续复用现有 `buildTaxonomy(posts)` 数据结果，不改变分类顺序、系列排序、标签排序或计数逻辑。
- 不引入新依赖，不修改文章内容、frontmatter 或筛选页行为。

## Non-goals

- 不重做首页、归档页、文章页或筛选结果页。
- 不增加标签过滤、搜索、折叠、推荐、图谱或动画场景。
- 不把文章索引设计成卡片仪表盘、数字花园插画页或可交互终端模拟器。
- 不更换全站字体、主题变量、壁纸或导航结构。

## Acceptance Criteria

- [x] 页面不再出现分类卡片、系列时间线和胶囊标签，主要视觉层级由排版、留白、对齐和少量细线构成。
- [x] 页头不含解释性句子，仅保留与归档页同量级的小号文章索引标题和中文文章数。
- [x] 分类、系列、标签看起来属于同一套目录系统，而非三个独立组件样式。
- [x] 系列名称与篇数在移动端可快速扫读，编号在长标题下不会错位。
- [x] 标签没有完整外框或胶囊底色，热度通过克制的颜色与计数表达。
- [x] 浅色主题保持复古纸张和锈红风格，深色主题保持 CRT 与终端绿风格，两者均不是纯黑白仿制 Steph Ango。
- [x] 页面内容宽度、水平/垂直留白、标题字号和 hover 反馈与归档页处于同一视觉系统，没有突兀的大字或贴边内容。
- [x] 像素字体只出现在小型元信息中，不承担长标题或大段内容，页面正文阅读清晰。
- [x] 320px、375px、768px 下无横向溢出，所有交互目标满足至少 44px 的可点击范围。
- [x] 移动端菜单仍为 6 个纯图标入口；桌面导航、GitHub、背景切换及侧栏无回归。
- [x] `/browse/` 的分类、系列、标签、数量和链接与共享 taxonomy 数据一致。
- [x] 生产构建通过，静态 HTML、title、meta、canonical 和 sitemap 保持正确。

## Notes

- 主要视觉参考：[Steph Ango](https://stephango.com/)。借鉴其排版秩序、主题文字云、列表密度和克制留白，不进行像素级复制。
- 本任务取代已归档任务 `09-05-mobile-index-refinement` 的索引页视觉方案；上一任务中的命名、路由、移动端纯图标菜单和无障碍能力继续保留。
