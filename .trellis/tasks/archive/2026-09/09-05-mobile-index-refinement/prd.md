# 移动端文章索引视觉与菜单调整

## Goal

在保留现有分类、系列、标签浏览能力和移动端 6 个一级入口的前提下，改善内容索引页的命名与视觉体验，使其更贴合博客轻盈、带有纸张质感和像素点缀的整体风格；同时将移动端展开菜单恢复为简洁的纯图标布局。

## Requirements

- 将当前界面名称「浏览」统一调整为「文章索引」：
  - 页面主标题使用「文章索引」；
  - 浏览器标题、meta description 和移动端入口的 accessible name 使用相同语义；
  - 保留现有 `/browse/` URL、canonical 和 sitemap 地址，避免产生失效链接或不必要的 SEO 迁移；
  - 分类、系列、标签筛选页继续视为文章索引的下属内容语境，入口激活状态不变。
- 重新设计移动端文章索引页的视觉层次，避免当前由直角边框、横线和规则方框主导的观感：
  - 延续全站现有的纸张背景、主题色、正文与像素字体，不引入独立于博客的新视觉体系；
  - 页头采用更自然的编辑式层次，由小型像素风引导文字、页面标题和简短说明组成，弱化硬质色块与贯穿式分隔线；
  - 分类使用带柔和圆角和轻量色阶的入口卡片，突出名称与篇数，但不使用厚重边框或硬阴影；
  - 系列使用具有阅读路径感的纵向列表，允许使用圆点、细线或序号等轻量引导元素，系列名和篇数保持一眼可扫读；
  - 标签使用胶囊形 chip，自然换行，通过轻微色阶表达热度，避免用明显字号跳变制造层级；
  - 区块之间主要依靠留白、文字层级和局部柔和底色分组，不为每一项重复绘制完整矩形边框；
  - 浅色、深色主题下都应保持柔和对比度、清晰层级和足够的文字可读性。
- 移动端（`<=768px`）展开菜单继续严格保持 6 个一级入口，顺序为：首页、归档、文章索引、关于、搜索、外观。
- 移动端 6 个入口仅显示图标，不显示图标下方或旁边的可见文字：
  - 六个图标使用一致的视觉尺寸、线宽和等宽六列布局；
  - 每个入口保留明确的 `aria-label` 或等效的屏幕阅读器文本，装饰性 SVG 不重复朗读；
  - 当前入口继续通过 `aria-current` 和可感知的图标状态体现，不能只依赖文字；
  - 搜索、外观切换等按钮仍需保留准确的动态 accessible name；
  - 每个入口的触控目标不小于 44×44px。
- 桌面端导航保持现状：不显示文章索引入口，继续显示 GitHub、搜索、背景与外观切换；桌面侧栏及其分类、系列、标签统计不变。
- 文章索引页继续使用现有共享 taxonomy 数据，不改变分类、系列、标签的内容、计数或排序规则。
- 不引入新依赖，不修改文章内容、frontmatter 或现有筛选页行为。

## Non-goals

- 不将 `/browse/` 重命名或迁移为新的 URL。
- 不重做全站布局、导航结构、主题变量或桌面侧栏。
- 不增加标签搜索、折叠、筛选、推荐或个性化能力。
- 不为每个分类、系列或标签新增插画、远程图片或独立图标资产。
- 不改变移动端菜单入口数量，也不恢复 GitHub 或背景按钮占用移动端一级入口。

## Acceptance Criteria

- [x] 页面所有面向用户的「浏览」命名均调整为「文章索引」，但访问 `/browse/`、刷新、后退及静态直达仍正常。
- [x] 页头、分类、系列、标签四个区域形成清晰而柔和的视觉层次，不再由重复直角矩形和贯穿式边框主导。
- [x] 分类入口使用柔和圆角卡片；系列列表具有连续的阅读路径提示；标签为胶囊形 chip，三者视觉语言协调且保留各自辨识度。
- [x] 浅色与深色主题下，文字、计数、交互状态均清晰可辨，没有过亮底色、低对比度文字或突兀硬边框。
- [x] 在 320px、375px、768px 视口下，页面无横向溢出，长系列名、标签和计数不会互相遮挡。
- [x] 移动端菜单展开后恰好显示 6 个纯图标入口，按首页、归档、文章索引、关于、搜索、外观排列，不显示可见文字。
- [x] 6 个图标的尺寸、线宽、对齐和点击区域一致；每个入口的触控区域不小于 44×44px。
- [x] 使用屏幕阅读器或可访问性树时，6 个入口均具有清晰名称；当前文章索引及其分类、系列、标签下属路由具有可感知的选中状态。
- [x] 769px 及以上桌面导航与侧栏没有视觉、入口或数据回归。
- [x] `/browse/` 的静态 HTML、document title、meta、canonical 和 sitemap 均通过生产构建验证，其中 URL 保持不变、展示名称更新为「文章索引」。
- [x] 首页、文章页、文章索引页及代表性的分类、系列、标签页面无控制台错误，菜单打开、关闭、Escape 和路由跳转行为保持正常。

验证备注：生产构建、静态 HTML/meta/canonical/sitemap、可访问性树与 CSS 断点均已检查；当前自动化浏览器接口不支持强制指定视口，320/375/768px 的布局由固定六列规则、隐藏文字规则和最小触控尺寸做代码级核验。

## Notes

- 命名采用「文章索引」：它准确描述按分类、系列和标签查找文章的功能，也能与按时间组织的「归档」形成区别。
- 「探索」更轻松，但容易让读者期待推荐或发现流；「主题」容易与外观主题产生歧义；「分类」则不能覆盖系列和标签，因此不采用。
- 本任务是已归档任务 `09-05-mobile-browse-taxonomy` 的后续调整；原任务文档作为已实现基线保留，不回写历史验收结果。
