# 修复文章版本对比准确性与阅读体验

## Goal

让读者准确理解历史版本到当前版本改了什么，同时保持博客正文的公式、链接、层级和阅读节奏。以《ZT1 关于矩阵》的真实版本为首要验收样本。

## Requirements

- 优先级 P0：长段插入后仍能正确对齐后文；未改动的参考列表不被标成删除后新增。
- 优先级 P0：差异阅读保留数学公式、链接、强调、代码和图片的语义与可读性，不泄露原始 TeX、不重复公式内容。
- 优先级 P1：中文小幅修改仅标出变动文字；整节新增作为连续区域呈现，减少重复标签。
- 优先级 P1：保留单栏正文内红删绿增的风格。普通文字删除有删除线，公式、代码、图片不被贯穿删除线。
- 优先级 P1：显示比较方向、变更处数、上一处/下一处及回到当前版本；统计与导航指向同一组变更。
- 保留默认折叠、点击展开的纵向历史列表，以及现有 compare 分享链接和自动收录正文变化的规则。
- 明暗主题、窄屏、键盘操作均可用；颜色之外提供文字/符号提示。
- 本任务进入实现阶段后交付代码、回归验证和可检查的本地预览；提交、归档和发布仍按 Trellis 完成阶段另行处理。

## Acceptance Criteria

- [ ] 固定旧版本 9413e8f2057e4c0182c0aad1203cab546f7a4104 与新版本 63529236ac24bab5dfcae397a5a71e447766aff8 的正文作为回归样本，不依赖之后变化的 HEAD。
- [ ] 新增“非方阵”内容不与原有“特征值与特征向量”“SVD 与伪逆”交错；参考标题及同内容列表仅出现一次且无差异标记。
- [ ] 章节编号变化可标注，但未改变的标题文字、段落不会因此整块重写。
- [ ] 含公式的修改段落保持完整 KaTeX；未变化公式仅渲染一次，不出现 MathML/TeX/视觉文本三份拼接。
- [ ] 连续中文单句改字、链接仅改目标、图片仅改地址、公式仅改内容均能正确发现并呈现。
- [ ] 连续新增内容合并提示；不同章节或被未改动内容隔开的变更不误合并；“待续”保留真实变化，不因低信息量被静默删除。
- [ ] 变更处数等于可导航区域数；首尾按钮禁用，无变化时无导航；切换版本清除旧定位状态。
- [ ] 目录只定位当前侧标题，ID 唯一；旧版本删除标题不混入当前目录。
- [ ] 375px / 768px / 桌面宽度及明暗主题视觉检查通过；页面不横向溢出，公式/代码必要时局部滚动；键盘焦点清晰并尊重减少动画设置。
- [ ] 历史加载失败、资源代际不匹配时展示当前正文；当前阅读与版本自动收录不回归。

## Notes

范围外：双栏编辑器、任意两历史版本互比、作者手动标记版本、全文折叠过滤、专门的移动检测、运行时后端、重新设计历史入口。真正移动的内容可以暂按删除/新增显示，不承诺识别为移动。

现有偏好足以制定方案，无阻塞性产品问题。研究证据与验证局限见 research/findings.md。
