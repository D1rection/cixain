# 完善碎片发布与链接可靠性

## Goal
让碎片可以安全地从草稿发布，并在文章、碎片、搜索之间保持一致且可校验的引用。保持现有无导航、靠链接与搜索访问的产品设计。

## 已确认问题
1. 新建模板未声明 draft，且写作说明会成为页面正文和自动摘要。
2. 碎片中的无前缀及 posts/ 链接错误继承 fragment 类型，和模板说明不符；搜索使用另一套默认规则。
3. 已有失效引用警告，但发布不阻断；普通 Markdown 中未注册目标未进入检查，普通标题锚点也未完整验证。
4. date 原样输出、updated 单独归一化，缺少非法日期和先后关系校验。
5. FragmentPage 正文请求地址未适配 BASE_URL，失败显示空白，缺少取消和重试。

## Requirements
- 模板默认 draft: true；保留 date/updated/tags，写作说明移出可渲染正文。既有文件不自动改成草稿。
- 统一双链解析：无前缀、post/、posts/ 指向文章；fragment/ 指向碎片；#heading、#^id、^id 为当前页。正文、搜索显示标题、引用校验和反向链接共享目标解析。
- 开发环境保留草稿预览及告警；生产构建拒绝新增失效内部内容引用。历史债务不得自动放行，只有明确枚举的已审核豁免允许暂存。
- fragment 日期输出统一为 YYYY-MM-DD；接受当前 YAML Date 和日期字符串，拒绝非法值，updated 不早于 date。draft 必须为布尔值；缺失保持历史兼容的 false。
- 加载正文区分加载中、成功、失败；可重试，支持子路径，切换/卸载取消旧请求，旧正文不串页。

## Acceptance Criteria
- [x] 新模板默认不进入生产页面、索引、sitemap、反向引用或可访问正文产物；开发可预览。
- [x] 文章↔碎片、同类引用、显式前缀、同文块/标题引用、中文 slug、别名均按统一契约解析。
- [x] 同名文章与碎片无隐式猜测，正文与搜索使用一致的目标标题。
- [x] 缺失目标、草稿/未来目标、缺失锚点和重复块 ID 有文件位置与修复提示；新增问题导致生产命令非零退出。
- [x] 合法闰日、非法日期、YAML Date/字符串、updated 早于 date、不同机器时区有测试；报错指出文件及字段。
- [x] 根路径和子路径下的直达/客户端切换可用；404/网络失败可重试；快速切页与取消不展示旧正文。
- [x] 独立副本中生产构建和回归测试通过，既有文章的发布规则未意外改变。

## Scope
仅修复上述内容链路。无需新增导航、碎片目录页、内容状态枚举、自动 slug 重命名、数据库或搜索算法。既有用户文章/碎片正文不批量修改，迁移建议单独列出。

## Open Questions
无阻塞问题。推荐规则已按现有模板、搜索约定及用户授权范围确定；实施前展示当前历史失效引用清单，若需豁免则逐项列明，禁止自动生成通配豁免。

## 实施结果
已完成自动化验收，证据及设备/部署验证边界见 research/verification.md。标题原文不会隐式转换为锚点，指南明确要求网页实际 ID；已修复的一条历史引用见 research/audit.md。
