# 视觉设计 v2：开放式导语

## 方向
总览直接排在文章页面上，与正文共用背景和左侧基线。通过主题色标题、柔和的文字和留白形成开篇层级。移除包围边框、独立底色、左右内缩、阴影；标题保留小号 route 图标。

这是根据用户“不做成卡片”的最新要求提出的方案，替代上一版纸面摘要框。用户已确认实施，代码已更新为本方案，尚未提交。

## 视觉规格
| 元素 | 方案 |
| --- | --- |
| 外观 | 透明背景、无四边框、无阴影、无圆角；与正文同宽且左对齐 |
| 标题 | 保留作者标题，默认“总览”；0.9375rem（15px，与内容一致）、600 字重、1.5 行高，主题强调色；保留 1em route 图标，无英文副标题或胶囊底 |
| 内容 | 0.9375rem（15px），正文色 60% 与 muted 色 40% 混合；不使用斜体或整体透明度 |
| 行高 | 沿用共享引用行高，含公式段落保留公式行高；两套主题几何一致 |
| 标题至内容 | 14px（rhythm-half） |
| 内容块间距 | 相邻段落和列表 14px，保留作者自由分段 |
| 收尾 | 内容结束后保留 28px 留白，不使用分隔线 |
| 外间距 | 上下 28px（rhythm-1）；后续正文接续现有文章块间距 |
| 水平内边距 | 0；桌面和手机均沿用文章本身的左右留白 |

标题可正常换行。总览与正文的字号差维持 15px 对 16px；标题、图标和总览内容统一为 15px，标题以字重和主题色区分。长段中文和公式不进一步压缩，手机端也不再缩小。

## 明暗主题
标题引用现有主题强调色（浅色锈红、深色绿色）；内容混合色引用全局正文与 muted 变量。背景透明，直接呈现文章自身表面。切换主题仅改变颜色。

## 实现边界
仍使用 `blockquote[data-callout="overview"]` 与现有构建输出。CSS 将 overview 的背景、边框、阴影与左右内边距清零，仅保留底部留白，不设置分隔线。用直接子元素选择器将标题 route SVG 设置为 1em，与文字基线对齐，沿用 6px 图文间距；不改生成器或嵌套 callout 图标。

段落与列表沿用上一轮限定直接子元素的间距规则；保留 KaTeX 的独立滚动及共享行高。其他 callout 和普通引用保持现状。

## 取舍与后续
不再用封闭边界识别总览，识别依赖标题、文字颜色和留白。避免加入分隔线或恢复左侧竖线，以免重新形成面板感。此方案已实施，typography 与 content-pipeline 规范已同步。
