# 文章底部模块：相关推荐 + 上下篇 + 版权声明

## Goal

利用文章底部现有 70vh 留白区域，添加三个信息模块：相关文章推荐、上一篇/下一篇导航、版权声明，并相应缩减留白。风格与博客现有设计语言一致（硬阴影、2px 边框、accent hover）。

## Requirements

- **相关文章推荐**
  - 基于 tags 重叠度匹配，最多 3 篇，排除当前文章
  - 无相关文章时整个模块隐藏
  - 卡片样式：标题 + 日期（风格参考 PostCard，但更紧凑）
- **上一篇 / 下一篇导航**
  - 按日期排序取相邻文章（date 降序，与列表排序一致）
  - 无上一篇或下一篇时只显示有的一侧
  - 两篇文章都没有时不渲染模块
- **版权声明**
  - 一行简短文本，链接到 CC BY-NC-SA 4.0 说明页
  - 复用 Footer 已有的版权文案风格
- **留白缩减**：`PostContent.module.css` 的 `padding-bottom: 70vh` 调整，由新增模块自身提供间距
- 模块位于文章正文之后、Footer 之前
- 桌面端与移动端均正常（移动端无 ToC，模块不依赖 ToC 布局）

## Acceptance Criteria

- [ ] 打开一篇文章，底部依次显示：上下篇导航、相关推荐、版权声明
- [ ] 相关推荐仅显示与当前文章有共同 tag 的文章，最多 3 篇
- [ ] 无共同 tag 的文章不显示相关推荐模块（不出现空模块）
- [ ] 首篇/末篇文章只显示单侧导航
- [ ] 点击模块链接跳转到对应文章/页面
- [ ] 深浅色主题下样式均正常，与博客风格一致
- [ ] 移动端布局正常无溢出
- [ ] 70vh 留白已缩减，文章底部不再有大量空白

## Notes

- 数据来源：`useBlogData()` 的 posts 数组（已有 title/date/slug/description/tags）
- 版权链接与 Footer 一致：https://creativecommons.org/licenses/by-nc-sa/4.0/
- 此任务不包含评论系统（已明确排除）
