# 博客内容排版呼吸感优化

## Goal

解决文章正文排版"没有呼吸感"的问题：以权威排版基准（中文 W3C clreq 系规范 + 西文网页排版最佳实践）为参照，重构正文区垂直节奏，让行距/段距/块距/标题间距形成清晰分级与整倍数节奏，并补齐暗色主题补偿。

## Scope（已确认）

- **文章正文排版为主**：`src/components/PostContent.module.css`（正文区全部间距/行高参数）+ `src/styles/global.css`（节奏变量定义 + 暗色补偿变量）。
- 不动文章页头（BlogPost.jsx）、列表页、侧栏、导航。
- 行宽保留 **680px**；字号体系（16/20/24/32rem）不变；不换字体；不动暗色色板（CRT 氛围保留）。

## Requirements

1. 建立垂直节奏体系：正文行高调至 **1.75**（16px → 28px 整数基线），全部块级间距落在 14/28/42/56px 栅格上。
2. 段落间距 ≥ 1×行高（28px），段落边界清晰可辨。
3. 标题间距分级：标题上方间距 ≥ 1.5× 下方；h1/h2/h3 行高收紧至 1.3（不再继承正文 1.75）。
4. 块元素（代码块/引用/callout/列表/图片/表格）间距统一按节奏栅格重排，替代当前一刀切 16px。
5. 暗色主题启用暗底补偿：正文行高 +0.05、字距 +0.01em（通过 CSS 变量随主题切换，不重复写选择器）。
6. 以 CSS 变量形式定义节奏 token（`--rhythm-*`），语义化命名，禁止散落魔法数字。
7. **与现有代码零冲突**：不改主题切换机制（`data-theme` 挂 html 的现状）、不覆盖任何现有组件样式（TOC/PostCard/PostEnd/页头/侧栏）、新变量命名空间不与现有一致（已排查 `--color-*`/`--font-*`/`--callout-*` 无冲突）。
8. **桌面端与移动端观感均达标**：桌面端为主方案；移动端（≤768px，沿用现有断点）沿用同一 28px 栅格但标题上方留白降档，行宽自动适配且无横向溢出。

## Constraints

- CSS Modules 规范不变（PostContent.module.css 为模块样式，global.css 只放全局变量/主题层）。
- 不引入新依赖、不引入 runtime fetch、SSG 构建链路不变。
- 亮色"复古纸张"与暗色"CRT 终端"双主题观感都要保持，只调排版节奏不动配色。
- 响应式断点沿用现有 `768px`，不新增断点；主题变量只加进现有 `:root/[data-theme='light']` 与 `[data-theme='dark']` 块内，保持其既有的覆盖优先级。

## Acceptance Criteria

- [ ] 正文区所有块级间距可被验证为 14/28/42/56px 节奏栅格值（li 微间距、代码/引用内边距为明确豁免项并注释说明）。
- [ ] p 间距为 28px；段落之间的视觉间隙 ≥ 单行行距。
- [ ] h2 上方间距 ≥ 1.5× 其下方间距；h2/h3 `line-height ≤ 1.35`。
- [ ] 暗色主题下正文行高/字距自动切换为补偿值（用 CSS 变量验证，theme 切换即时生效）。
- [ ] max-width 保持 680px；字号 16/20/24/32 体系不变。
- [ ] `npm run build` 通过；dev 预览下亮/暗双主题各截屏人工对比，正文区无拥挤、间距分级可辨。
- [ ] 长文（如含长代码块/表格/多 callout 的文章）不出现间距异常（margin collapse 校验）。
- [ ] 冲突回归：文章页 TOC 滚动定位、PostEnd/页头、列表页卡片排版与改动前一致（对照截图抽查）。
- [ ] 移动端 375px 视口：文字框 ≈21 字/行、标题间距紧凑合理、无横向溢出、暗色补偿同样生效（截图验证）。
