# 保留公式字体的可换行说明

用户已批准开始实现，并要求英文保留公式字体。方案为正常 Markdown 说明 + 显式 `[!mathtext]` 引用标记，不改变数学内部布局。

- 在现有 `rehypeCallout` 中识别 `[!mathtext]`；输出普通 blockquote，以 `data-mathtext` 标识，移除标记且不生成标题、图标或 callout 表面。
- `rehypeMathText` 在块 ID 解析之后为引用块直接子段落中的自然语言文本生成 `span.math-text`，包含链接/强调内的文本；跳过数学、code、pre 和嵌套引用。提前包装会影响 `^id` 的挂载层级，必须有块锚点回归覆盖。
- 在 `PostContent.module.css` 中为 `.math-text` 设置 KaTeX_Main、1.21em、1.2 行高及零字距。文字和数学分别使用同一基础字号，避免在整个块放大字体导致公式再乘一次 1.21。
- 父段落沿用现有引用行高和间距，引用背景/边线与独立公式滚动不变。
- 草稿中只增加显式标记并拆出三段英文；已有用户内容保持不变。以编辑前副本为依据检查变更范围。
- 更新内容编译版本使历史缓存失效；普通引用/callout 输出契约不变。
- 回滚：还原三个说明段落及标记，移除编译分支和样式；保留用户其它内容。

此标记在博客中是无标题旁注板；Obsidian 会将未知类型显示为默认 callout，其内部正文仍为普通 Markdown。不会自动推断文章语义或给所有含公式的引用改变字体。
