# 实施与验证（2026-10-01）

## 实现

prepareMD 通过 unified 非字符串 compiler 结果保留最终 HAST 与原 VFile；全站一次转换后建立源标题/实际 ID 索引，再 resolveMDLinks 修改关联 wiki 节点并收集普通 URL。校验通过后 renderPreparedMD 才序列化、写文件。compileMD 保留原参数和返回字段，并包装同文/外部索引解析。

源标题在 Markdown 行内格式/高亮转换后、HTML 与 KaTeX 前记录，最终绑定实际 ID；不更改既有 ID 算法。完整 wiki 原文和行列保留，URL/wikilink 明确区分。歧义、失效与可见性仍受原生产门禁控制。

content/anchor-index.json 为忽略的构建中间产物；历史编译复用解析器及当前索引，wiki 跳到当前正文规范地址。compilerVersion 带 headings-1，generation 额外包含索引 hash，确保目标文章改动 ID 后也重新生成历史比较。非法索引 strict 失败，非 strict 清除指针、保留最新正文。
