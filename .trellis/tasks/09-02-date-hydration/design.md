# 技术设计

## 边界

在 `src/utils` 增加纯函数日期格式化工具，输入 frontmatter 的 ISO 日期或可解析日期，优先读取字符串的日历日期部分；在 PostCard、BlogPost、PostEnd、Archive 中复用。对 Sidebar 的标签排序改为不依赖运行时 locale 的确定性比较。

## 数据流

文章元数据 → 日期工具提取 `YYYY-MM-DD` → 组件输出固定的 `YYYY/M/D` 或补零格式。标签集合 → code-point 字符串比较 → 服务端和客户端相同顺序。

## 兼容性与取舍

- 保留现有组件的视觉格式：卡片/文章结尾补零，文章页和归档标题不补零。
- 对非标准日期保留 `Date` 作为兜底，但不把 UTC 零点再转换成本地日期。
- 不以客户端挂载作为修复手段，避免首屏闪烁和 SEO 内容缺失。

## 回滚

变更集中在日期工具、四个调用点和 Sidebar 排序；可通过单个提交整体回滚。
