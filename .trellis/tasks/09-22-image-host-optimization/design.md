# 图床优化设计

## 决策

保留 PicGo → GitHub → jsDelivr 及现有 URL；优先修正上传处理、连接启动、失败恢复。正文编译不引入网络依赖。图片压缩减少传输量，但不解决跨境连接延迟；CDN 命中也不保证客户端连接快。

## P0：让上传规则生效

当前 local 模式不会执行已填写的自定义规则。实施时通过 PicGo 保存以下配置，重新打开核对；仅记录插件字段，不把包含 token 的完整配置写进仓库。

```text
压缩方式：custom
允许 PNG 质量下降：false
图片质量：0
图片格式自动转换：off
自定义压缩流程：
ext=png,size>=300KB=>mode=local,png_lossy=false,convert=off,on_failed=break; ext=*=>mode=off,convert=off
```

300KB 为避免小图额外 CPU 工作的起点，并非性能定律。精确字节阈值以安装版本解析器为准，测试两侧及相等情况。on_failed=break 确保失败/变大返回原图，避免未来落入其他转换规则。

处理发生在上传前，无需监控剪贴板或新增快捷键。PicGo 可能把剪贴板内容先转成 PNG，所以判断以 PicGo 接收的实际格式为准。无损验收需比较解码后的像素和尺寸，含普通 8-bit 截图、透明图；特殊位深/色彩元数据单独核验，必要时原样通过。PNG 无损开关不约束 WebP 编码，不把 quality=100 当作无损。

## P1：连接预热和失败恢复

### 连接提示

index.html head 增加一个指向 https://cdn.jsdelivr.net 的 preconnect，可配套 dns-prefetch。普通 img/CSS 跨域请求按实际凭据模式匹配，不机械添加 crossorigin。SSG 从模板继承，核对首页/文章/404 无重复提示。

提示不保证浏览器执行或必然提速。保持 200px 懒加载作为起点，不同时放大阈值、预载所有图片或全部背景。

### 图片状态

idle → loading → loaded/error；error 经读者操作再次进入 loading。首期只提供手动重试，不做超时竞速和自动循环重发。

- 保存原 data-src，一次点击只发出一次同 URL 请求；loading 期间禁用重复操作，成功移除重试入口。
- 用可键盘操作的按钮，将重试与打开灯箱明确分离。
- 先核对安装的 vanilla-lazyload 版本重置机制，不能照用新版 API。
- 修正 setPlaceholderTheme：仅替换 idle 占位图，不能覆盖 error 图或 loading 请求。
- 路由离开清理监听器，陈旧请求不修改新页面；保留 HtmlSegment 的 memo 行为。
- 灯箱提供失败提示/重试，索引变化隔离旧图片状态；背景失败保留旧背景并轻量反馈。
- 不改向 raw.githubusercontent.com 或随机镜像，不追加时间戳 query 破坏缓存。

## P2：测量后再决定

### 固定背景

对四张公开背景离线比较无损 PNG/WebP 的体积与解码像素。若收益明显，可作为站点静态资源随部署分发，不涉及作者 PicGo 流程。先实测博客主机与 CDN，不能假设同源必然更快。

后续若采用：保留原图，以新文件名发布；桌面初始化、导航切换、移动 CSS 使用一致清单。只请求对应屏幕的当前背景，不预取整套背景。保持主题、像素风和切换行为，不强制把体积压到“几十 KB”。此项不属于首期代码实施范围。

### 首屏请求启动

若浏览器瀑布证明 JS 初始化明显推迟首屏图，再设计生成 HTML 中的 eager 例外。第一张图不一定在首屏；需兼顾折叠块、交互片段和历史正文。首期不整体替换懒加载机制。

### 独立诊断工具

可提供按需图片审计，不挂到日常写作/构建命令。仅访问允许的公开图床域名，去重、并发 <=2、超时和下载量有上限，输出体积、HTTP 状态和各阶段耗时；不读 token、不上传遥测。审计失败不阻止发文。

## 取舍

| 候选 | 结论 |
| --- | --- |
| 固定 commit URL | 长缓存不保证首访快，需要自动版本映射或额外维护，首期暂缓 |
| 构建镜像/转换正文图 | 增加构建网络依赖，与当前零网络图片编译规范冲突，暂缓 |
| 全局 WebP | 默认编码/截图质量风险，暂缓；明确无损且自动化后可另评估 |
| 多 CDN 竞速 | 增加请求与故障面，无目标网络测量，不采用 |
| 大 PNG 无损 + 预热 + 重试 | 不增日常操作，可独立回退，作为首期 |

## 验证与回退

取多图大图文章、小图文章、桌面首页、移动端背景。相同设备/网络下冷浏览器缓存及热缓存各 5 次，记录代理状态。浏览器冷缓存不等于 CDN 冷缓存；比较中位数和最慢样本，不拿小样本声称可靠 p95。

记录 DNS/连接/TTFB/下载、请求发起与图片显示时间；跨域 Resource Timing 受限制时用 DevTools。测试快速滚动、灯箱、主题、历史比较、hash、离线/恢复在线。已有缓存不发背景请求是正常情况。

上传配置切 off 即原图上传；连接提示与失败恢复分项回退；后续背景清单可指回旧 URL。首期不改既有链接，因此无需远端覆盖或 purge。
