# 按文章数量排序分类和系列

## Goal

文章索引页的分类与系列列表按文章数降序排序

## Requirements

- 在文章索引页中，分类和系列均按文章数量从高到低排列。
- 文章数相同时，分类维持站点配置中的现有顺序；系列按最近文章日期从新到旧排列，日期仍相同时按系列名升序排列。
- 分类、系列的文章数继续根据当前加载的文章数据计算。
- 保持标签索引当前按文章数降序的行为。

## Acceptance Criteria

- [ ] 分类显示顺序符合文章数降序；当前数据应为：技术 16、题解 6、随笔 1。
- [ ] 系列显示顺序符合文章数降序；当前数据应为：CS229 机器学习 10、算法 2、图形学 2、CMU10-414 深度学习系统实验 1。
- [ ] 分类或系列计数相同时，按上述稳定规则排序。
- [ ] 分类和系列链接及计数展示保持正常。
