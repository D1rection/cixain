# 开篇“总览” Callout 设计

## 定位

“总览”用于文章标题与正文之间，帮助读者快速预览全文结构和阅读路线。它强调文章的整体脉络；现有 `[!abstract] 摘要` 继续用于正文中的局部摘要或概念归纳，两者用途不变。

正文不设固定格式或长度。作者可以用段落、列表或其他常规 Markdown 自由说明。

## Markdown 形式

```md
> [!overview] 总览
> 在此自由组织整篇文章的概述与阅读路线。
```

`overview` 是独立类型标记；“总览”是默认标题，作者可按文章内容自行调整标题和正文。

## 视觉方向

- 在文章正文内容宽度内呈现为醒目的横幅，不延伸到页面视口边缘。
- 保留现有 callout 的矩形卡片与硬阴影语言；以蓝色系专属强调色、较明显的浅色/深色主题底色和强调边缘，形成更高的视觉层级。
- 标题使用清楚的“总览”字样，配路线或地图意象图标（优先使用 `route`），标题与图标采用强调色。
- 正文保持正常阅读字号和 Markdown 排版，不强制生成目录、分栏或固定字段。
- 保证浅色与深色主题中标题、图标和正文有足够对比度；色块用于提示类型，不降低正文可读性。
- 与文章标题和正文之间留出适度间距，使它像文章入口，同时不盖过标题。

## 实施边界

本次更新 `Templates/callout.md`、Markdown callout 图标映射、总览专属主题颜色与横幅样式，并同步更新前端内容管线规范。不限制总览正文内容的段落或篇幅，不改动既有 callout 的表现。
