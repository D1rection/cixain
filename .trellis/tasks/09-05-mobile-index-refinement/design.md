# 移动端文章索引视觉与菜单调整 — 技术设计

## 1. 设计边界

本任务只调整已存在的 `/browse/` 文章索引页与移动端 `NavBar` 的呈现层。分类、系列、标签仍由 `buildTaxonomy(posts)` 提供，筛选页路由与桌面侧栏数据不变；`/browse/` URL 继续作为稳定的外部地址。

## 2. 命名与信息架构

- 用户可见名称统一为「文章索引」：页头、document title、meta description、导航 accessible name 均采用该语义。
- `/browse/` 作为兼容路由保留，不新增重定向或第二个页面地址。
- 页面层级保持「页头 → 分类 → 系列 → 标签」，但通过留白与不同的表面形态区分三种入口。

## 3. 视觉方向

- 延续 `global.css` 的纸张浅色主题、CRT 深色主题、accent 色和像素字体。
- 用圆角、低对比底色、留白和局部 accent 取代重复的直角边框；不使用厚重阴影。
- 分类是轻量圆角卡片；系列是带连续路径提示的纵向行；标签是胶囊 chip。
- 交互状态以 accent 色、浅色背景变化和 focus-visible 轮廓共同表达；深色主题不能依赖纯白高亮。
- 避免为每个条目创建独立插画或远程资源，保证首屏轻量和现有像素风统一。

## 4. 移动端导航

移动端仍渲染固定六个一级入口：`首页 / 归档 / 文章索引 / 关于 / 搜索 / 外观`。GitHub 与背景入口只在移动端隐藏，桌面端规则不变。

- 继续使用六列等宽布局和现有 SVG 图标。
- 移除移动端可见文字，图标保持统一 18px 视觉尺寸与线宽。
- Link/button 必须有清晰 accessible name，SVG 标记为装饰性内容；当前状态保留 `aria-current` 和 accent/背景反馈。
- 触控目标至少 44×44px；菜单按钮保留 `aria-expanded`、`aria-controls`、Escape 关闭和路由变化关闭。

## 5. 兼容与回滚

- 不改变数据结构、筛选页、桌面导航或静态路由生成方式。
- 若视觉方案需要回滚，只回退 `Browse.module.css` 与文章索引文案；保留共享 taxonomy 和 `/browse/` 路由。
